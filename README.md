# Moiz Ahmed Khan — Professional CV & Portfolio

Multi-page static website prepared for GitHub Pages.

## Pages
- `index.html` — Home
- `cv.html` — Professional CV and download
- `experience.html` — Work experience
- `projects.html` — Filterable project portfolio
- `research.html` — Research and publication
- `contact.html` — Contact details

## Publish on GitHub Pages
1. Create a new public repository, for example `moiz-portfolio`.
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Before publishing
- Confirm employer/client permission for project names and descriptions.
- Replace or remove any confidential project information.
- Review dates and job titles.
- The home address and identity-number information are intentionally omitted.
